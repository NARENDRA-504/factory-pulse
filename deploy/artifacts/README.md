# Reviewed model artifact

`health-model-v2/model.json` and `evaluation.json` are the checksum-verified portable
Random Forest and synthetic evaluation, copied from the locally trained artifact.
No credentials, account records, raw training data or operational telemetry are included.
The model remains **shadow-only** and fails its physical-validation and Critical
precision/recall release gates. It must not control machinery or replace threshold alerts.
Vector model weights/indexes are optional and deliberately not bundled here.
